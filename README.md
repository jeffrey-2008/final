# Campus Toolkit
Two student tools in one page, switched by tabs:

- **Free Class Locator** — find empty classrooms floor-by-floor from the SRM Trichy EEE-school timetables (Odd Sem 2026-27), with a natural-language room finder, a 3D building map with live countdowns, and a WhatsApp "Call the Squad" invite.
- **Attendance Predictor** — 75% detention math, 90% recovery target, an OD/leave simulator, a projection chart and a built-in Advisor.

Open `index.html` in a browser — no build step. Deep links: `#locator` and `#attendance`.
